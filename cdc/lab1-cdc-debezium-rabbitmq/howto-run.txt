docker compose up -d rabbitmq

create a queue called my_cdc_queue name and bind it to amq.topic with routing key my_cdc_queue




1. Declare the Queue

docker exec -it cdc-rabbitmq rabbitmqadmin -u admin -p password declare queue name=my_cdc_queue durable=true


2. Bind the Queue to amq.topic

docker exec -it cdc-rabbitmq rabbitmqadmin -u admin -p password declare binding source=amq.topic destination=my_cdc_queue destination_type=queue routing_key=my_cdc_queue


3. Verify the Binding
To verify the setup from the CLI without using the web UI:


docker exec -it cdc-rabbitmq rabbitmqadmin -u admin -p password list bindings
